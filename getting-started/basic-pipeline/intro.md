# Introduction to the Tekton Pipeline

[Tekton](https://tekton.dev) is a powerful and flexible open-source framework
for creating CI/CD systems, allowing developers to build, test, and deploy
across cloud providers and on-premise systems.

In this tutorial, you will learn:

- How to create a Tekton **Task**
- How to create a second Task
- How to build a **Pipeline** from multiple Tasks
- How to run a Pipeline and check its logs

While the environment loads, Tekton Pipelines and the `tkn` CLI are being
installed in the background. This may take a minute or two.
