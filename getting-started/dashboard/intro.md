# Introduction to the Tekton Dashboard

The [Tekton Dashboard](https://github.com/tektoncd/dashboard) is a web-based UI
for Tekton Pipelines. It allows you to monitor and manage your Tasks, Pipelines,
and their runs through a graphical interface.

In this tutorial, you will learn:

- How to install and access the Tekton Dashboard
- How to create Tekton Tasks and Pipelines
- How to create and monitor PipelineRuns from the Dashboard
- How to view logs of running and completed PipelineRuns

While the environment loads, Tekton Pipelines, the Tekton Dashboard, and the
`tkn` CLI are being installed in the background. This may take a minute or two.
