# Dashboard + Triggers: Monitoring Event-Driven Pipelines

When you combine the Tekton Dashboard with Tekton Triggers, you get a powerful
UI for monitoring event-driven CI/CD workflows. The Dashboard displays Triggers
resources (EventListeners, TriggerBindings, TriggerTemplates) and lets you watch
PipelineRuns appear in real-time as webhooks fire.

In this tutorial, you will learn:

- How to **view Triggers resources** in the Dashboard UI
- How to **monitor webhook-triggered PipelineRuns** in real-time
- How to **debug failed triggers** using Dashboard visibility

**Prerequisites:** Familiarity with Tekton Triggers and the Dashboard.

While the environment loads, Tekton Pipelines, Dashboard, and Triggers are being
installed. This may take a minute or two.
