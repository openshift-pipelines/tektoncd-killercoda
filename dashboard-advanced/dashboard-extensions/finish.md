# Congratulations!

You have learned how to use **Dashboard Extensions** to add custom resource
views to the Tekton Dashboard.

## What you learned

- Dashboard extensions add **custom resource types** to the sidebar
- How to **register extensions** via the Extension CRD or labels
- Viewing and managing **custom resources** alongside Tekton resources

## Key points to remember

- Extensions support any namespaced Kubernetes resource
- The Extension CRD specifies apiVersion, kind, and display settings
- Useful for viewing ConfigMaps, Secrets, CRDs alongside Pipelines
- Dashboard extensions are an alpha feature
