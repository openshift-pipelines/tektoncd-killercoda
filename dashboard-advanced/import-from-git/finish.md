# Congratulations!

You have learned how to **import Tekton resources from Git** using the Dashboard.

## What you learned

- The Dashboard **Import feature** for pulling Tekton YAML from Git repositories
- Importing **Tasks** from repository subdirectories
- Importing and running **Pipelines** from Git-hosted definitions
- **Managing imported resources** through the Dashboard UI

## Key points to remember

- The Import feature clones a repo and applies YAML to a target namespace
- Label imported resources for easy identification and management
- Works with any public Git repository containing Tekton YAML
- Private repos require Git credentials configured in a Secret
