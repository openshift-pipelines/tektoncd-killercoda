# Congratulations!

You have successfully installed and managed Tekton using the Tekton Operator.

In this tutorial, you learned:

- How the Tekton Operator creates and manages a **TektonConfig** resource
- How to switch between **profiles** (all, lite, basic) to control which
  components are installed
- How to **configure Tekton features** like `enable-api-fields` through
  TektonConfig

The Operator is the recommended way to manage Tekton in production environments.
It provides a single declarative resource that controls your entire Tekton
installation, handles upgrades, and ensures consistent configuration.

To learn more, explore these resources:

- [Tekton Operator documentation](https://tekton.dev/docs/operator/) - Full Operator reference
- [TektonConfig reference](https://tekton.dev/docs/operator/tektonconfig/) - All configurable fields
- [Tekton documentation](https://tekton.dev/docs/) - Full documentation for all Tekton components
